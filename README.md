## What I build

I like owning problems end-to-end, from architecture to deployment. I gravitate toward web development, agentic AI, distributed systems, and things that serve real users.

- 🎬 **[The Cinephile's Van](https://www.cinephilesvan.com/)**: A production web app aggregating 70+ weekly indie cinema screenings in Vancouver. React/Next.js frontend, Node.js REST API, automated AI-powered ETL pipeline, deployed on AWS.
- 🧠 **[Pitchcraft AI](https://github.com/fever-ride/pitchcraft-ai)**: AI proposal automation turning 3-day agency workflows into 30-minute pipelines. 7-agent LangGraph orchestration with 5 human-in-the-loop checkpoints. Multi-layer RAG architecture: campaigns are decomposed into atomic propositions, contextually embedded, and retrieved via per-agent profiles with parent-child expansion. Cross-client knowledge accumulates with every archived project. FastAPI + Next.js + MongoDB + Pinecone.
- ⚡ **[DropBid](https://github.com/fever-ride/dropbid)**: Real-time auction platform. 6-service Java microservices, Redis Streams for event-driven messaging, Redis Lua scripts for sub-50ms bid acknowledgement under concurrent load, AWS ECS with auto-scaling.
- 🔐 **[ShieldScan](https://github.com/fever-ride/shieldscan)**: Event-driven DevSecOps platform. Automated SAST/DAST, Claude API as a ReAct agent for security triage, Terraform infrastructure.
